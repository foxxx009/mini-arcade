About Mini Arcade

Mini Arcade is a small collection of browser games built to load fast and work everywhere: phones, tablets, laptops, old hardware and slow connections.

What is here

Stack Tower — a timing and precision stacking game. 2048 — the well-known number merging puzzle. Snake — the classic grid game. Reflex Test — a five-round reaction time measurement.

How it is built

Plain HTML, CSS and JavaScript with no frameworks and no build step. Nothing is downloaded at runtime beyond the page itself, which keeps the games small and quick to start. Controls work with keyboard, mouse and touch, so the same page works on a desktop and a phone.

More games

The collection grows over time. If a game you want is missing, the site is open source and new games can be added as single files.
